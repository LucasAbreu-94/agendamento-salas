# Fluxo mockado do MVP

1. O Portal apresenta o acesso **Agendamento de Salas**.
2. O usuário informa a necessidade da reserva.
3. A API retorna salas mockadas compatíveis.
4. O usuário escolhe uma sala e revisa os detalhes.
5. A confirmação gera apenas uma mensagem visual de sucesso.

Esse fluxo serve para demonstração e não cria eventos reais em calendários corporativos.
