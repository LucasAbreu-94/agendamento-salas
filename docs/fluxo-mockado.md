# Fluxo mockado do MVP

1. O usuário entra pelo Portal da empresa e abre **Agendamento de Salas**.
2. A tela inicial já é o mapa: ele informa data, horário, duração e quantidade de pessoas no painel de resumo.
3. A API retorna as salas compatíveis com a necessidade.
4. O usuário escolhe uma sala livre na planta e revisa o resumo.
5. A confirmação fica disponível após o login e, nesta etapa, gera apenas uma mensagem visual de sucesso.

Esse fluxo serve para demonstração e não cria eventos reais em calendários corporativos.
